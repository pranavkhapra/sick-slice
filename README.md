# sick-slice

Sick slice is online pizza store that includes all the features of a real world food delivery website.Where you can view pizza on based on toppings with dynamic pages for each pizza , and their makers knowns as slicemasters ,order them which is send to the shop for delivering.

For the **Frontend**-
It's build on **Gatsby** a _React.js_ Framework to do all the stuffs like (Routing ,Scoped CSS ,Preloading ,SEO ,building dynamic pages , pagination and filtering ).

For **Backend** used  **Sanity.io**(A headless CMS) for making admin managing interface , data relationships , schemas.

Used *Graphql* for getting the data from Sanity to Gatsby using queries. 

Declared *serverless function* for completing the order by sending email of the order.

Created *honey pot* to defend against bots.
