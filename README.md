# sick-slice

Sick slice is online pizza store that includes all the features of a real world food delivery website. 
It's build on Gatsby a React.js Framework to do all the stuffs like (Routing ,Scoped CSS ,Preloading ,SEO ,building dynamic pages , pagination and filtering ).
For Backend used  Sanity.io(A headless CMS) for admin managing interface , data relationships , schemas 
Used Graphql for getting the data from Sanity to Gatsby using queries. 
Used serverless function for completing the order by sending email of the order.
Created honey pot to defend against bots.
